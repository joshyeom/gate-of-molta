룰 변경 흐름

1. 누군가 12점 도달 즉시 게임을 끝내지 않고 현재 라운드 종료 상태로 전환합니다.
2. 남은 플레이어 진행 같은 라운드에서 뒤 플레이어도 추월할 수 있습니다.
3. 다음 라운드 진입 시 종료 트리거된 라운드를 넘어가면 게임 오버로 확정합니다.
4. 최고 점수 승리 점수 우선, 동점이면 다이아 수로 승자를 계산합니다.

핵심 수정 영역

R엔진 룰

  • 12점 도달 즉시 종료를 제거하고 “현재 라운드 끝까지 진행”으로 변경했습니다.
  • 최종 승자는 라운드 종료 시점의 최고 점수로 다시 계산합니다.
  • 복수 결제 플랜을 반환해, 같은 조건을 여러 방식으로 만족할 때 사용자가 고를 수 있습니다.
  • 활성 카드의 가상 진주와 값 변환을 손패 진주보다 우선 활용할 수 있게 했습니다.

C카드 효과

  • 1111: 원하는 1-8 진주로 간주되어 조합에 참여합니다.
  • 333/666: 두 조건 후보를 모두 실제 결제 후보로 평가합니다.
  • 345: 방금 사용한 진주 중 되돌릴 카드를 사용자가 선택합니다.
  • 상대 관문 버림: 자동 스킵 대신 대상 관문 카드를 직접 고릅니다.

UUX / UI

  • 행동 상태를 상단 바에서 제거하고 각 플레이어 보드에 남은 행동 수를 표시합니다.
  • 상대 활성 카드를 스크롤 없이 볼 수 있도록 펼쳐진 필드 레이아웃으로 바꿨습니다.
  • 모바일과 좁은 화면에서 카드/관문/활성 영역이 무너지지 않도록 반응형을 정리했습니다.
  • 불필요한 중앙 플래시 애니메이션을 제거하고 카드 제거 후 다음 카드가 나오도록 조정했습니다.

M선택 모달

  • 활성 조건을 만족하는 조합이 2개 이상이면 후보 선택 모달을 띄웁니다.
  • 후보에는 손패 진주, 활성 카드, 다이아 사용 여부를 구분해서 표시합니다.
  • 패시브 효과라도 사용자의 선택이 필요한 경우 먼저 모달을 띄웁니다.
  • 다른 사람 턴에도 카드 상세는 읽을 수 있고, 실제 활성화만 막습니다.

AExpert AI

  • 난이도별 가중치를 분리하고 Hard/Expert에서 견제 가중치를 높였습니다.
  • 상대 유력 카드, 필요한 진주, 마켓 인물 선점 가치를 계산합니다.
  • Expert가 관문을 비워둔 채 진주만 가져가는 상황을 줄였습니다.
  • 불필요한 진주 시장 새로고침보다 배치/활성/견제를 우선합니다.

V검증

  • 엔진 테스트에 12점 라운드 종료, 1111, 345, 상대 관문 선택 회귀 테스트를 추가했습니다.
  • Expert 10판 배치 시뮬레이터를 추가해 전체 게임 완료와 불변식을 점검했습니다.
  • 검증 산출물은 JSON으로 보존해 이후 비교 기준으로 사용할 수 있습니다.
  • Vercel 프로덕션 배포 후 200 응답까지 확인했습니다.
