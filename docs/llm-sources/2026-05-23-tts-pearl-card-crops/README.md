# TTS Pearl Card Crops

Pearl-card reference crops cut directly from the Steam/TTS source card sheets in `../2026-05-23-tts-reference-assets` using crop geometry recorded in `../2026-05-23-tts-card-crops/manifest.json`.

These files are reference/source material only. Do not use them as final app assets unless rights are confirmed. Use them to verify pearl-card values, icon placement, and replacement-asset planning.

The set contains the standard pearl values 1-8 plus the visible character-refresh variants for pearl values 3, 4, and 5.

See `manifest.json` for source sheet, row/column, and crop metadata. Open `review.html` in a browser for quick visual inspection.

`imagegen-prompts/` contains image-to-image restoration prompts for generating high-fidelity, clearer versions with a generative model while preserving the source card identity and layout.
