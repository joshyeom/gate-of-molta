# TTS Card Crops

Individual card crops derived from the reference card sheets in `../2026-05-23-tts-reference-assets`.

These files are reference/source material only. Do not use them as final app assets unless rights are confirmed. Use them to inspect card composition, icon placement, and visual style while creating new original assets.

See `manifest.json` for source sheet, grid, and crop geometry metadata.

Open `review.html` in a browser to verify the TTS character metadata, candidate score/diamond reward values, and cropped card images one by one. Cards with matching cost/effect/reward signatures are grouped next to each other.
